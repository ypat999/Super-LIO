有。结合你目前已经完成的实验，我认为下一阶段不应继续以“调参找到更小的楼层 yaw 误差”为主，而应当把问题拆成三个层次：

1. 误差从哪里进入系统：IMU 传播、点云去畸变、坐标变换、观测构建，还是地图更新。
2. 误差如何被放大或固化：螺旋楼梯的几何退化、迭代线性化、地图代表点更新，是否将小误差转化为每层同方向的 yaw 偏差。
3. 什么机制能区分这些假设：用同一份 rosbag 做代码级对照实验，直接比较中间量，而不是仅比较最终轨迹。

你已有的实验已经提供了一个很重要的约束：同一份数据仅改变配准参数，就能明显改变墙面偏航斜率；而陀螺仪 scale 改变 0.2%，最终 yaw 几乎不变。 因此，下一步最值得追查的，是观测更新与退化几何之间的耦合，以及时间、坐标和地图数据链路中是否存在稳定的方向性误差。

以下是我建议新增的排查计划，均不重复你文档中已经列出的 `kf_max_iterations`、`g_obs_weight` 和 `ApplyDeltaCorrection` 时间分配实验。

## 一、优先级最高的新增排查项

我会按“能否区分根因、实现成本、对现有证据的解释力”排序。前四项建议优先做，且多数只需增加日志或做离线对照，不必马上修改算法。

### P1：分离 IMU 先验与 LiDAR 观测对 yaw 的逐帧贡献

最高优先级

要回答的问题： 观测更新是在纠正原本正确的 IMU 预测，还是在将预测中的小误差固化成系统性偏差？

你已有的累计统计表明，观测净修正只有约 +3.38°，而 IMU 预测累计约 −167.53°。但累计量会掩盖局部正负抵消，不能直接证明 LiDAR 观测对 yaw 的影响很小。

新增排查：

- 每帧记录预测姿态 \\(R_k^-\\)、观测更新后的姿态 \\(R_k^+\\)。
- 记录预测 yaw 增量、观测更新造成的 yaw 增量，以及二者的差值。
- 将上述数据按楼层、下降转角、平台转弯段和楼梯段分组统计。
- 额外统计观测更新的绝对值之和、正负方向占比及其与局部几何退化指标的相关性。

判读： 如果各层都出现很小但同方向的更新偏差，且偏差与几何退化程度相关，支持“观测更新持续引入方向性误差”；如果观测更新主要在抵消预测误差，则应继续查 IMU 传播、时间同步或去畸变。

### P2：检查残差是否存在随方位角变化的系统性偏置

要回答的问题： 是否有一部分点云在每层都产生相似的 yaw 力矩？

你目前主要关注总体拟合残差、有效点比例和匹配失败率。但总体残差小，不代表残差在空间分布上没有偏置。

新增排查：

- 将有效匹配点按 LiDAR 水平方位角分桶，例如每 15° 或 30° 一组。
- 对每组统计有符号点到平面残差，而不只是绝对残差或 RMSE。
- 分别统计楼梯内壁、外壁、平台、天花板和地面等不同几何区域。
- 统计各组对 yaw 方向的 Jacobian 贡献，观察误差是否集中于某些方位或结构。

判读： 如果某些方位角的残差长期同号，或者内外壁提供的 yaw 约束互相矛盾，就可能存在几何采样不均、对应关系偏置或地图局部形变。这个实验比单纯增加点数更有诊断价值。

### P3：检查地图反馈是否形成误差自强化

要回答的问题： 一个微小的位姿偏差，是否会通过地图更新变成下一帧更稳定的错误解？

你之前观察到，出现楼梯断层后，后续会一直沿错误姿态建图。这意味着除了状态估计，还必须检查地图更新是否存在反馈效应。

新增排查：

- 每帧保存地图更新前的局部地图版本或可复现快照。
- 记录新插入点数、被保留或替换的体素代表点数，以及局部地图覆盖范围。
- 比较错误姿态附近的地图几何，观察是否在连续帧中被强化。
- 对同一段 bag 做两组离线实验：正常更新地图；冻结地图更新，仅用已有地图继续匹配。

判读： 若冻结地图后偏差增长明显减缓，说明地图反馈可能是重要放大环节；若冻结后仍以相近斜率漂移，误差更可能来自观测求解或传播链路。

注意，冻结地图会改变系统运行条件，不能直接用两组轨迹的最终误差判断根因；应重点比较同一短时间窗内的 yaw 更新和残差变化。

### P4：核查坐标系、重力方向与旋转误差的耦合

要回答的问题： 看似纯 yaw 的偏差，是否实际来自姿态误差在楼梯运动过程中向 yaw 投影？

新增排查：

- 核对 LiDAR、IMU、机体及世界坐标系的轴向、旋转方向、外参应用顺序。
- 检查欧拉角 yaw 增量是否始终使用一致的参考系与解缠绕方式；必要时直接使用相对旋转矩阵或四元数分析。
- 记录每帧 roll、pitch、重力方向及其变化，检查 yaw 偏差是否与倾斜姿态相关。
- 检查 IMU 到 LiDAR 的外参旋转是否在传播、去畸变、观测构建中使用一致。

判读： 如果 yaw 误差与 roll/pitch 变化存在稳定相关性，应重点查坐标变换和旋转参数化，而不是继续调整陀螺仪比例系数。

这里不是认定外参存在错误，而是要排除一个能够产生稳定方向性误差、但容易被误认为 yaw 漂移的机制。

## 二、第二优先级：补齐容易被忽略的误差链路

### P5：IMU 与 LiDAR 的时间戳、点时间和帧边界

你已经修正了去畸变中使用原始 gyro、而 ESKF 使用去 bias gyro 的不一致，并验证它没有显著改变墙面斜率。因此，不建议再次围绕同一个 bug 做重复实验；应该转向更完整的时序审计。

重点检查：

- IMU 时间戳是否严格单调，是否存在重复、间隔突变或丢样。
- LiDAR 点时间是相对帧起点还是帧终点，单位是否一致，是否发生过错误的时间偏移。
- `back_time`、当前帧时间和 IMU 缓存的起止边界是否一致。
- 一帧点云中是否混入了上一帧或下一帧时间范围的点。
- `Propagation_Undistort` 使用的角速度和 ESKF 传播采用的积分区间是否一致。

建议每帧输出以下统计量：

| 指标                  | 用途           |
| ------------------- | ------------ |
| IMU 样本数、首末时间戳       | 检查采样覆盖与丢样    |
| 点云首末点时间、有效时间跨度      | 检查点时间定义      |
| IMU 与 LiDAR 的时间覆盖缺口 | 检查去畸变输入是否完整  |
| 被丢弃的超时点数、比例         | 检查帧边界行为      |
| 传播区间与去畸变区间差值        | 检查两个运动模型是否一致 |

判读重点： 如果异常帧或楼层偏差的增长与时间覆盖缺口、帧边界或转弯角速度有关，就应先解决时序问题，再解释配准残差。

### P6：检查观测方程中的平移—旋转耦合

这和你已计划补充的退化特征值分析不同：不仅看“有没有退化”，还要看误差沿什么方向进入状态更新。

在观测线性化后，记录按平移和旋转划分的 Jacobian 信息块，以及它们之间的交叉项：

\\[ H = \begin{bmatrix} H\_{tt} & H\_{tr}\\\ H\_{rt} & H\_{rr} \end{bmatrix} \\]

这里的分块应对应实际观测残差对平移、旋转扰动的 Jacobian，而不是直接把未经尺度归一化的状态矩阵当作可观性指标。

建议：

1. 对同一帧记录 \\(H\_{tt}\\)、\\(H\_{rr}\\) 的特征值和特征向量。
2. 单独检查平移—旋转交叉项 \\(H\_{tr}\\)。
3. 将最弱约束方向转换到世界系，检查是否与楼梯下降方向、墙面切向或绕井道运动方向接近。
4. 对比正常楼梯段、平台段和出现地图断层前后的变化。

判读： 如果 yaw 自身的约束并非完全缺失，但它与某个弱约束平移方向存在强耦合，求解器可能在不同的平移—旋转组合之间选择代价相近的解。这比单纯观察 `cond(Yk)` 更能解释“局部 xyz 看起来正常，但跨楼层 yaw 累积偏移”的现象。

### P7：检查 ESKF 协方差与增益是否放大了退化观测

你已确认 `imu_na/ng` 在当前实现中直接作为 \\(Q\\) 对角项使用，而不是先平方的标准差；同时减小 IMU 噪声在楼梯场景表现更差。因此，继续扫 IMU 噪声参数的优先级不高。

但仍值得检查实际状态更新中，协方差如何影响 LiDAR 观测的权重。

需要记录：

- 更新前后姿态协方差，特别是 yaw 对应的方差。
- Kalman 增益中与 yaw 相关的行，以及与平移、速度、bias 的交叉项。
- 观测更新前后 yaw 的变化量，与实际观测信息强弱之间的关系。
- 长时间运行后，协方差是否持续收缩，即使观测几何已不足以提供可靠约束。

判读： 如果退化方向上的协方差持续收缩，意味着滤波器可能对实际不可靠的观测过度自信。即使每帧修正量很小，长时间重复更新也可能使偏差难以恢复。

这项检查应先观察真实矩阵，再决定是否修改协方差传播或退化方向的更新策略，不建议预先增加任意的 yaw 限幅。

### P8：检查对应点与地图代表点的空间分布偏置

你已做过 `rep_mode=1`，结果影响很小；子体素 μ clamp 也已证明是恒等操作。因此，没必要重复验证这两个方向。

更有价值的是检查对应点的空间分布：

- 有效匹配点是否长期集中在某一侧墙面。
- KNN 失败是否集中于特定高度、方位角或几何结构。
- 同一体素内的代表点替换，是否导致匹配点在空间上产生偏向。
- 法向估计在内外壁、楼梯边缘、平台接缝处是否存在方向性误差。
- 每层几何结构变化时，实际参与 yaw 约束的点是否突然发生偏移。

建议按楼层和空间区域统计匹配点数量、法向分布、残差均值和对应点覆盖范围。重点不是单纯提高有效匹配率，而是确认有效匹配点是否具有足够均衡且可信的空间分布。

## 三、第三优先级：用可控实验区分算法机制

上述排查能发现异常，但要判断哪一项真正解释了每层固定方向的 yaw 偏差，还需要几组更有针对性的实验。

### P9：构造已知运动的合成数据

不必一开始就搭建完整的仿真环境。可以先构造可控的 IMU 与 LiDAR 输入，逐步增加复杂度：

1. 静止场景，验证姿态是否稳定。
2. 已知纯 yaw 旋转，检查角度符号、积分和去畸变。
3. 已知 yaw 加平移，检查旋转—平移耦合。
4. 模拟螺旋楼梯的墙面和平台几何，再逐步减少可观测结构。

每组输入都应有精确的轨迹真值。这样可以区分：误差来自基础坐标和时序实现，还是只在退化几何与地图反馈同时存在时才出现。

### P10：将同一段 bag 按楼层分段重放

选取三类区间：普通楼梯段、楼层平台段、以及进入断层或弯曲开始明显的区间。

对每个区间分别统计：

- IMU 预测的 yaw 误差趋势。
- LiDAR 更新带来的 yaw 增量。
- 残差方位分布与退化特征。
- 地图更新前后的几何变化。

如果每层的误差增量近似固定，但平台段能显著改变误差方向或幅度，说明几何结构与运动模式很可能共同决定偏差，而不是一个简单的固定 gyro bias。

### P11：比较前向与反向通过相同楼层

你已有的往返数据中，最终回到起点时闭环误差只有厘米级，因此不能用终点闭环误差作为主判据。但前向与反向经过同一结构时，局部误差增量仍然有诊断价值。

分别比较同一楼层、同一平台附近的 yaw 增量和墙面偏航斜率：

- 若偏差随运动方向反转，优先检查运动畸变、时序、动态匹配与方向相关的观测偏置。
- 若偏差始终偏向同一个世界方向，优先检查地图几何、坐标变换及固定结构带来的系统性约束偏差。

这只是区分机制的证据，不是单凭正反向对比就能确定根因。

## 四、我会如何安排实际执行顺序

考虑到你已经有自动实验脚本、`debug.csv` 和明确的基线，我建议分成三个阶段，避免同时修改太多模块。

## 阶段 A

只加日志

先做 P1、P2、P4、P5。

不改变算法行为，新增逐帧 yaw 更新分解、方位角残差分布、姿态变化、时间覆盖和帧边界统计。这一步最重要，因为它能确定接下来究竟应该动哪个模块。

## 阶段 B

单变量对照

做 P3、P6、P7、P8。

优先选取一段包含明显误差增长的楼梯数据，对地图更新、观测求解和协方差分别做独立对照。暂时不改变正式算法，只验证哪个环节能解释误差增长。

## 阶段 C

机制验证

做 P9、P10、P11。

对最可疑的机制构造已知运动、分段重放和反向对照。只有当结果可以重复，并且预测的中间量与实测相符，才进入算法修改。

## 五、结合现有证据，我认为最值得优先验证的三个假设

| 假设                       | 关键证据                   | 最有区分力的实验     |
| ------------------------ | ---------------------- | ------------ |
| 退化几何下的观测求解存在方向性偏置        | 同一 bag 的配准参数明显影响墙面偏航斜率 | P1 + P2 + P6 |
| 地图更新将小的姿态误差固化并放大         | 断层形成后，后续轨迹持续沿错误姿态建图    | P3           |
| 时序或坐标链路将运动误差转化为固定 yaw 偏差 | 楼梯段持续旋转、局部坐标误差不明显      | P4 + P5 + P9 |

其中第一项是目前最值得优先验证的工作假设，但尚不能称为已确认根因。你已完成的实验支持“配准机制强烈影响最终残余偏差”，还没有证明误差一定是在配准层最初产生的。

我的具体建议： 先不要再做大范围参数搜索，也不要马上引入新的退化检测或回环机制。先补齐 P1 的逐帧预测—更新分解，并结合 P2 的有符号残差方位分布。如果这两项能定位到稳定的方向性观测偏置，再沿 P6 深挖 Jacobian 与状态更新；如果观测更新并没有持续引入偏差，则把重点转到时序和坐标链路。这样能最大程度避免继续投入在已经被实验削弱的假设上。
